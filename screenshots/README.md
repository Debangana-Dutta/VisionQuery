# screenshots/

Add screenshots of the running Streamlit app here (e.g. `app-home.png`,
`app-prediction-example.png`) once you've run `streamlit run app/app.py`
and tried it yourself.

No screenshots are included in this ZIP — they should be captured from your
own actual run of the app, not fabricated, so that your portfolio accurately
represents what you built.

Suggested screenshots to capture for your README / portfolio:
1. The empty app (image upload + question box, before asking anything).
2. An uploaded image with a question typed in, before clicking "Ask Question".
3. The predicted answer displayed after clicking "Ask Question".
4. (Optional) The warning banner shown when no fine-tuned checkpoint is
   present, to demonstrate the graceful fallback behavior.
